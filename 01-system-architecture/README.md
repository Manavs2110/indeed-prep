# Systems Architecture exercises

**Format:** 45–60 min, no code. Draw on paper, Excalidraw, or HackerRank's whiteboard. Better: have a friend play interviewer and reveal one twist every ~10 minutes.

**Framework to follow each time:** Requirements (5) → Estimates (3) → API + data model (7) → High-level design (10) → Deep dive (15) → Production readiness (5).

Open each twist only after your base design is done. When a twist lands, say *what changes and why* — don't start over.
